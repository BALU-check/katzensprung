# Katzensprung

Ein kleines Jump & Run mit sechs Leveln: Die Katze Minka klettert über Mauern und Bäume zu ihrer Schale Milch.
Zum Spielen am Handy im Querformat. Jedes Level hat eine eigene Seite (`level1.html` bis `level6.html`),
die Übersicht `index.html` zeigt für jedes Level einen QR-Code.

Steuerung: ◀ ▶ laufen, Sprung-Knopf springen. Gegen eine Mauer oder einen Baumstamm laufen = klettern.
Am Computer: Pfeiltasten und Leertaste.
